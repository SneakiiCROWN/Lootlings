# Lootlings

A fantasy loot adventure with combat, equipment, expeditions, a Hub, a personal Home and an illustrated Archive.

**Current prerelease: 0.4.76 test · Android code 88.**

## Download and play

1. [Download the Windows ZIP](https://github.com/SneakiiCROWN/Lootlings/releases/download/lootlings-v0.4.76-public-test-20261020/Lootlings-Windows-0.4.76-Test.zip).
2. Right-click it, choose **Extract All**, then open the extracted folder.
3. Double-click **Lootlings.exe** and keep its supporting files together.

On Android, [download the installable APK](https://github.com/SneakiiCROWN/Lootlings/releases/download/lootlings-v0.4.76-public-test-20261020/Lootlings-Android-0.4.76-Test.apk), open it from Downloads and choose **Install**. Android may ask permission for that browser or file manager to install trusted downloads.

No coding tools are needed. GitHub’s **Code → Download ZIP** contains source, not the playable program.

## Updating without losing progress

Extract each Windows version into a new folder and keep the old folder for rollback. Keep your existing settings and save folders; do not reset or delete app data to update.

This APK uses **com.sneakiicrown.lootlings**, code **88**, with the existing local signing certificate (SHA-256 starts `fe1e5f882df56d16`). It updates compatible normal local builds while retaining app data. The earlier GitHub app **com.sneakiicrown.lootlings.friends** used a temporary key unavailable locally. The owner app **com.sneakiicrown.lootlings.owner** is also separate. Keep those installed to preserve their progress; no cross-app migration is supplied. Never uninstall an older app just to install this one.

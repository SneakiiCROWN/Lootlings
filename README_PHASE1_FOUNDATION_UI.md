# Lootlings Phase 1 Foundation UI v1

This pack implements the first production-art wave requested by ASSET_NEEDED_PHASE1.md.

Included:
- canonical Lootlings wordmark extracted from the established art direction
- 5 nine-slice dialog/panel skins
- 15 button state assets (primary/secondary/destructive × normal/hover/pressed/disabled/focus)
- 2 profile input skins
- combat HUD header and build ribbon shells
- HP/XP/enemy frames + fills
- 3 section dividers

All files are PNG sRGB RGBA and use the exact project-relative filenames requested by Codex.

Nine-slice guidance:
- panel_*: 32 px protected corners
- button_*: 24 px protected caps
- input_*: 24 px protected caps
- HUD shells: preserve ornamental edge/corner zones; stretch central field only
- bars: stretch horizontally; keep rounded caps intact

This pack intentionally does NOT include icon families yet. Those are Wave 2 and should be generated consistently from the canonical Lootlings art language rather than as text-token substitutes.

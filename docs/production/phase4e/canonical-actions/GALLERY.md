# Canonical combat action native gallery

84 full-resolution JPEGs: 18 controlled before + 66 after. Quality 94, no resizing. These are native desktop GLES3 phone/tablet layouts, not physical S23 captures. Target-driven facing; no forced-facing flag.

Before disables only the eight new source routes. Staged clock captures compare the same action/staging; live captures separately advance the actual game update and attack code. Missing left/recovery art stays TEMP.

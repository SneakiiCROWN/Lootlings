==================================================
1. CORE PHASE-4 DESIGN RULE
==================================================

Lootlings must NOT become a linear story game where cleared levels become useless.

Story progression UNLOCKS regions and systems.

Every region must then function as a long-term replayable farming destination.

Players should have reasons to say:

“I want X item/material/blueprint, so I’m farming that region.”

Build the replay loop around:

RUN
-> loot/resources/mastery/blueprints
-> Hideout
-> forge/unlock/build
-> choose another character/weapon/target
-> harder or stranger run
-> rare drops/secrets
-> repeat

Avoid mandatory daily login/FOMO/energy systems.

The game should be compelling because of progression, collection, buildcraft and discovery — not artificial punishment.

==================================================
2. PLAYABLE HUMAN ROSTER — START NOW
==================================================

Audit the current project for any approved/canonical human character references or assets.

If production-usable authored assets already exist, integrate them properly.

Do NOT fake “finished” final human art if required authored assets do not exist.

Create the SYSTEM and roster entries now for a first human cohort with genuinely different gameplay identities.

Target initial archetypes such as:

- stylish agile melee woman
- ranged / bow / precision woman
- heavy warrior / knight man
- rogue / magitech ranged man

Final names, canon, stats and details should fit the Lootlings world bible.

Each human needs:
- distinct silhouette/body identity
- starting perk
- strengths/weaknesses
- weapon affinities without hard class locking
- unique mastery progression
- appropriate voice/audio identity
- left/right weapon support
- readable mobile silhouette
- biography/lore hooks
- cosmetic expansion potential

Do NOT simply copy beast stats onto human bodies.

If final authored art is missing, clearly identify exactly which art sheets/poses are required and complete all safe system/content integration around them without lying about production readiness.

==================================================
4. CHARACTER + WEAPON MASTERY
==================================================

Implement an original Lootlings Mastery system inspired only at a high level by successful collection/progression games.

Characters and weapon families gain mastery through USE.

Mastery should reward experimenting with the roster.

Create an account-wide progression layer such as:

RELIC RANK

Relic Rank can unlock appropriate things such as:

- Forge capability
- advanced contracts
- higher expedition tiers
- additional build slots
- cosmetics
- rare crafting options
- new systems/content access

Do NOT make raw account rank simply invalidate earlier content.

Avoid pay-to-win/FOMO structures.

==================================================
5. FORGE / BLUEPRINT SYSTEM
==================================================

Create a reason to hunt specific content.

Introduce:

- blueprints
- blueprint fragments where useful

- rare crafting components

Possible source types:

- bosses

- rare events

- secrets

The Forge must create TARGET FARMING.

Players should be able to learn where broad categories come from without every secret being spoiled.

Keep it visually simple and satisfying.

==================================================

Add optional Hideout contracts that send players back into existing regions.

Examples of objective TYPES:

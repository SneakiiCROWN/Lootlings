# Install the owner-test candidate

1. Copy `C:\Users\Snkii\Documents\lootlings\builds\android\Lootlings-0.4.75-owner-test-debug.apk` to the S23 Ultra using USB or your usual file transfer.
2. Open the APK in My Files. If prompted, allow installation from that app, then choose Install/Update.
3. Update the existing owner-test app; do not uninstall it if you want to retain its isolated owner saves. The regular game package is separate.
4. Open Lootlings and check title → Hub → Shop/Stash/Forge → Home/Archive, then adventure and return dialogue.

Windows: keep `Lootlings-0.4.75-candidate.exe` and its matching `.pck` together in builds/windows, then open the EXE. Existing073 files are rollback candidates.

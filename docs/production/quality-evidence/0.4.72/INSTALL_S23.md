# Install the 0.4.72 owner test

1. Connect your Samsung S23 Ultra to the PC by USB and choose File transfer.
2. Copy `C:\Users\Snkii\Documents\lootlings\builds\android\Lootlings-0.4.72-owner-test-debug.apk` into the phone’s Downloads folder.
3. On the phone, open My Files → Downloads and tap that APK. Allow installation from My Files if Android asks, then choose Install/update.
4. Keep the previous owner app installed: this update uses the same owner application ID and signing key. Do not uninstall or clear its data. Normal Lootlings remains separate.
5. Open Lootlings Owner Test. On the title, tap the blue logo crystal seven times within three seconds, then hold the eighth contact at least0.8seconds and release. Tiny SHH reopens the existing menu. Test progress stays separate from normal saves.

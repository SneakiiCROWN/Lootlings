==================================================
CORE PRODUCT RULE
==================================================

Lootlings is:

CAMPAIGN
+ REPLAYABLE EXPEDITIONS
+ TARGETED DUNGEONS
+ RELIC SIEGE ENDLESS MODE
+ PERSISTENT COLLECTION / FORGE / MASTERY

The RUN resets.

The PLAYER'S COLLECTION does NOT.

Permanent:
- characters
- owned weapons
- armour
- jewellery
- relics
- blueprints
- forged equipment
- weapon upgrades
- character mastery
- weapon mastery
- Relic Rank
- materials
- boss components
- Archive discoveries
- cosmetics
- region unlocks
- difficulty unlocks

Temporary per-run:
- Run Scrip
- run blessings
- run curses
- proc combinations
- temporary stat stacks
- merchant inventory
- temporary event modifiers
- run-only evolutions

A failed run must still provide some meaningful permanent progress.

==================================================
1. RELIC SIEGE — FIRST PLAYABLE VERSION
==================================================

Create an original round-based survival mode.

Do not directly reproduce Call of Duty Zombies maps, assets, names, UI,
puzzles, characters, perks or protected mechanics.

Capture the FEELING:
- escalating rounds
- increasingly strange runs
- build adaptation
- map progression
- secrets
- miniboss interruptions
- elite chaos
- boss milestones
- “one more round” tension

Working player-facing name:
RELIC SIEGE

Use this unless an obviously stronger canon name already exists.

Initial playable Siege should support:

- endless rounds
- one selected owned character
- permanent owned equipment foundation
- heavy run-specific RNG
- Siege-only currency
- milestone encounters
- extraction decisions
- increasingly valuable reward pools
- score / highest round tracking locally

Do NOT require internet.

==================================================
2. ROUND STRUCTURE
==================================================

Use predictable milestones PLUS random disruption.

Suggested initial structure:

Rounds 1–4:
baseline enemies, room/map learning, first purchases

Round 5:
guaranteed elite event

Rounds 6–9:
higher density + RNG event chance

Round 10:
guaranteed miniboss/boss checkpoint
reward room
EXTRACT or CONTINUE

Every 5 rounds:
guaranteed meaningful pressure event

Every 10 rounds:
major encounter + reward/extraction checkpoint

Between milestones:
weighted chance for:
- surprise elite
- elite pack
- rare named elite
- miniboss invasion
- shrine
- merchant
- challenge room
- resource anomaly
- curse/blessing event
- environmental modifier

Do NOT simply scale enemy HP endlessly.

==================================================
3. ELITES
==================================================

Elites must alter decisions, not just gain health.

Build a reusable elite-affix framework.

Candidate original affixes:
- Vampiric: heals through nearby deaths/damage
- Stormbound: chains electricity through units
- Bulwark: protects nearby enemies
- Blink: teleports/repositions
- Gravecaller: revives defeated enemies
- Greedborn: carries bonus Siege currency but may escape
- Cursed: imposes a temporary debuff but carries enhanced rewards
- Frenzied: cadence/speed pressure
- Mirrorbound: temporary retaliation/reflection windows
- Hoarder: steals dropped currency until killed

Use readable mobile telegraphs.

Allow multiple affixes only at deeper rounds where readable.

==================================================
4. MINIBOSSES / BOSSES
==================================================

Mix guaranteed and RNG encounters.

Guaranteed:
- progression milestones
- every major round band
- map/secret progression

RNG:
- rare invasion minibosses
- named elite/miniboss encounters
- rare boss variants

Rare named enemies should create:
“WHAT THE FUCK IS THAT?”
moments.

They may have:
- unique Archive entry
- unique loot table
- blueprint fragment
- cosmetic
- boss material
- RED-tier component chance

Do NOT reuse a normal enemy with only inflated stats and call it a boss.

Existing art debt must remain explicitly tracked.

==================================================
5. SIEGE RNG
==================================================

Relic Siege should contain MORE run RNG than ordinary expeditions.

Possible systems:
- Blessing Shrine
- Cursed Shrine
- Greed bargain
- temporary relic machine
- mystery room
- wandering merchant
- challenge room
- weapon evolution choice
- environmental mutation
- rare NPC
- secret room
- unusual elite combination
- boss mutation

RNG must produce interesting decisions.

Avoid:
- unreadable clutter
- constant interruption
- pure lottery progression
- long droughts with no permanent progress

==================================================
6. RUN BUILD INSANITY
==================================================

Let temporary Siege builds become much more extreme than campaign builds.

Examples of SYSTEM interactions:
- projectiles ricochet
- elemental chains
- kill explosions
- shatter
- bleed propagation
- summoned effects
- temporary lifesteal
- crit-trigger transformations
- projectile duplication
- cursed high-risk effects

These expire when the Siege ends.

Permanent weapon balance must not be destroyed by allowing these effects
to permanently transfer into normal modes.

==================================================
7. SIEGE ECONOMY
==================================================

Add a dedicated SIEGE-ONLY currency.

It is earned during the current Siege.

Spend it on:
- temporary upgrades
- random weapon/relic machinery
- shrine activation
- map mechanisms
- temporary services
- run recovery
- reward spinner where appropriate

Siege currency disappears when the Siege ends.

Do NOT use real-money currency.
Do NOT allow premium purchases.
Do NOT require ads.

==================================================
8. END-OF-RUN RELIC SPINNER
==================================================

Implement a FUN end-run sink for leftover RUN currency / Siege currency.

This is NOT paid gambling.

No real money.
No purchasable premium currency.
No ad requirement.

Player may spend leftover run currency on a limited number of spins.

Suggested reward families:
- Scrap
- Gold
- regional material
- blueprint fragment
- boss material
- mastery bonus
- named-item cache
- rare crafting component
- extremely rare RED fragment/item where allowed

Region/mode should affect the reward pool.

Cap meaningful spins, e.g. 3–5 per completed run.

Use increasing spin cost so hoarding does not produce 30 boring spins.

Example:
100
175
275
400

Tune from simulation rather than blindly using these exact numbers.

The spinner must NEVER outperform actually completing difficult content
as the best farming strategy.

==================================================
9. RED-TIER CHASE
==================================================

Add the foundation for the highest chase rarity.

Working rarity designation:
RED

Final lore-facing rarity name can be more original if appropriate.

RED items should be:
- extremely rare
- distinctive
- build-defining or prestigious
- permanently owned
- upgradeable
- visually obvious
- tied to meaningful sources

RED sources may include:
- specific dungeon boss
- secret boss
- deep Siege milestone
- region-specific endgame challenge
- extremely rare full drop
- blueprint/fragment completion

Do NOT use pure tiny-RNG-only acquisition.

Use:
RARE COMPLETE DROP
+ FRAGMENTS
+ DROUGHT/PITY PROTECTION
+ TARGET FARMING

Players must be able to make eventual progress even while unlucky.

==================================================
10. TARGETED DUNGEONS
==================================================

Add the architecture for replayable Dungeons.

Initial dungeon structure should support:
- specific region identity
- specific enemy families
- distinct modifiers
- miniboss
- main boss
- target loot pool

- rare/RED chase

Dungeons are NOT one-use story stages.

They are farming destinations.

A player should be able to think:

“I need THIS component, so I am going THERE.”

==================================================
11. ANYWHERE PROGRESS + TARGET FARMING
==================================================

Critical balance rule:

ANY mode should advance some useful progression.

SPECIFIC modes/regions should advance specific goals faster.

Examples:

Play anywhere:
- Gold
- Scrap
- mastery
- Relic Rank
- general progression

Play Mossglass:
- Mossglass materials
- poison/nature blueprints
- Mossglass boss components
- Mossglass named drops

Play a specific Dungeon:
- targeted set
- exclusive blueprint
- specific boss component
- RED chase

Play Relic Siege:
- Siege mastery/progression
- deep-round rewards
- Siege-specific named items
- rare RED opportunities

Never make favourite content feel useless.

15. RETENTION GOAL STRUCTURE
==================================================

Every player session should expose:

SHORT GOAL
e.g. next chest / wave / upgrade

MEDIUM GOAL
e.g. finish blueprint / bounty / forge upgrade

LONG GOAL

==================================================
16. FAILURE REWARDS
==================================================

Dying should hurt but not erase the evening.

In Siege:
- mastery earned stays
- some general resources stay
- Archive progress stays
- bounty/achievement progress stays where appropriate

High-value extracted loot may require successful extraction.

This creates risk without total frustration.

==================================================
17. EXTRACT OR GREED
==================================================

At major Siege checkpoints:

EXTRACT
- secure eligible rewards
- end safely

CONTINUE
- increased reward multiplier
- increased rare-event weighting
- increased difficulty
- risk some unsecured loot

Do NOT risk permanently owned gear.

This should create:
“Fuck it, ten more rounds.”
moments.

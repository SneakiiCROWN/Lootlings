# Final delivery validation

On the final exported canvas with origin top-left, +X right/+Y down, measure palm contact centres (not wrists), Core/eye centre if present, actual supporting anatomy ground boundary, pivot, alpha bounding box, and launch/contact anchors. Ground Y is the boundary below the last occupied supporting pixel. Exclude shadow, lifted feet, FX and speckles. Record final pixel coordinates to 0.01px where available; record uniform source-to-canvas transform and SHA256 after export. Never copy another pose's coordinates.

- Validate mandatory fields/types against the appropriate schema. Template markers are forbidden in completed delivery.
- Body and foreground layers have identical canvas, transform, pixel alignment and identity. Alpha must stay inside the owning maximum bounds, with no speckles. A foreground composite includes both contacting hands where required; optional split layers replace that composite contract rather than creating debt twice.
- Ground target is an exclusive boundary; lowest supporting occupied row equals baseline-1. Hovering anatomy uses documented hover reference, never fake feet.
- Primary grip/contact aliases agree. Secondary point is a real second shaft/pair/string contact only when the state requires contact. Open bow release hand is not the nock. Cast origin remains attached to hand/staff/focus.
- Tail centreline starts at body/hip and ends at the single tail tip, ordered with smooth taper. Hoard Dragon tail_count=1, connected complete silhouette.
- Equipment transform is uniform; module grip maps exactly to measured palm. Layer order and depth are explicit; no VFX contact repairs.
- Source/runtime filenames agree with delivery listing. Final PNG hash and metadata view/state agree. Runtime registration is gated by visual acceptance; schema validation alone is insufficient.
- Read the Gloomlet accepted legacy sidecars as examples of working measured contact, NOT as numeric templates to paste into another pose.

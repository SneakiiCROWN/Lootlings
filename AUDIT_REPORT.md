## Coverage and limits

The initial inventory covered 700 files, 360 text files, all 247 PNGs (190 runtime / 45 reference / 12 source) and every WAV. Every PNG was examined on complete contact sheets; native captures cover HUD/panels/buttons/meters/cards, selectors, residents, story/lore, all weapon families, encounter groups, rewards/Forge/routes and regional backgrounds. The latest reviewed set contains 232 full-screen outputs plus twelve actor fit sheets, twelve sling sheets and five authored adult sheets. Contact-sheet review is not a pixel-by-pixel certification of every anatomical phase. Full-resolution Mosskin sling and long-title captures were checked separately. Incorrect transient capture fixtures/encoding output were corrected and regenerated; superseded captures are not production evidence.

All current root/test/tool GDScript parses. Text/path/hash/case/dimension/transparency/import and JSON decoding scans cover individual files; [file-status.csv](docs/audit/2026-10-02/file-status.csv) distinguishes this mechanical coverage from manual review. No filename case collisions were found. Literal missing-path candidates were optional production-audio delivery paths, an intentional negative test and prose punctuation; import/boot/runtime tests found no concrete broken active path. Dynamic paths are covered by exercised fixtures, not a proof of all possible runtime combinations.

Focused manual code review covered save/migration, lifecycle, inventory/economy persistence, input, presentation, fit/avatar/wardrobe, encounters/campaign/route wiring, debug gating and audio routing/provenance. Gameplay/economy assertions and seeded runs provide broader coverage; not every line of every large script received manual reasoning review. `lootling.gd` and `hideout_ui.gd` remain maintenance hotspots; only small integration/consumer changes were made. Player text/names/lore received mechanical full-text and displayed sample review, with documented aliases/identity contracts checked by canonical/resident tests; no exhaustive linguistic or lore-proof claim is made. Enemy/boss, prop/item/chest/shrine/vendor, projectile/VFX and cosmetic assets were inventoried and visually sampled in their runtime/category context; incomplete production deliveries stay explicit.

Runtime PNGs occupy about 109 MiB; the summed uncompressed RGBA footprint is 340.13 MiB if all are decoded concurrently, not measured residency. Most imports are lossless with no size cap. No bulk compression/downscaling was applied without mobile quality/budget evidence. All-resources export preserves dynamically loaded runtime content; further orphan pruning needs reference evidence and runtime coverage. Debug code remains gated by debug build/explicit opt-in; real release behavior is not certified by a debug-engine PCK boot.

FINAL means accepted within an existing delivery scope; LIVE means active/tested; BETA means provisional; REFERENCE means preserved source/research; STALE means superseded; MISSING means undelivered. These labels must not be conflated with release approval.

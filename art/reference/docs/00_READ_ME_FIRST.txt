LOOTLINGS — FULL ART PRODUCTION MASTER v1

PURPOSE
-------
This pack defines the COMPLETE visual-art scope required to take Lootlings from
a prototype/vertical slice to a coherent, launch-ready game presentation.

It is intentionally broader than the older 211-entry art manifest.

The previous manifest was strong for:
- playable characters
- environments
- weapons
- treasure chests
- NPCs

It did NOT fully cover:
- complete enemy runtime art
- equipment/item icon library
- currency/resource art
- UI iconography and states
- HUD/menu frame systems
- VFX sprite/effect library
- props/interactables
- boss presentation art
- store/marketing artwork
- app/store icons
- splash/loading presentation
- tutorial visual assets
- accessibility/localization-safe UI states
- social/achievement collection art
- final launch screenshots/promotional compositions

RULE
----
Do not ask Codex to invent or fake final production art while this art program
is still being completed.

ChatGPT owns:
- visual direction
- generation
- source research
- commercial-use/license verification
- production packaging
- naming and handoff

Codex should later own:
- import/integration
- pivots
- animation hooks
- VFX implementation
- runtime UI
- audio integration
- QA/tests/Git

STYLE NORTH STAR
----------------
Cute first.
Badass second.
Stylish/confident third.
Fantasy always.

High-level design lessons may be taken from:
- Overwatch: silhouette/readability/character appeal
- Diablo: dark fantasy, demonic menace, premium loot
- D&D / LOTR / Witcher: grounded fantasy materials/worldbuilding
- Borderlands: punchy loot identity/personality

No direct copying of franchise-specific characters, UI, music, logos,
weapon designs, maps, or other protected assets.

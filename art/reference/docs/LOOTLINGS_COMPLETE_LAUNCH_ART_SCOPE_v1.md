# LOOTLINGS — COMPLETE LAUNCH ART SCOPE v1

## Production Strategy

The financially smart approach is NOT to create hundreds of totally unique
assets when modular visual systems can produce greater variety.

Lootlings will use:
- strong canonical base art
- reusable rarity frames
- reusable enemy variant overlays
- reusable VFX families
- modular equipment presentation
- palette/material variation where it still looks authored
- pose+tween animation instead of expensive full frame-by-frame animation

This keeps the game rich without turning art production into an impossible
budget.

Future concepts can remain reference-only until monetization/retention data
justifies production.

## F. Enemies

Do not create 60 totally unrelated enemy rigs just because every zone has named
enemy families.

Production model:
- 24 canonical base enemy species across the full game
- 5 runtime poses each:
  idle, anticipate, attack, hurt, defeated
- 12 reusable variant overlay/effect kits:
  Hasty, Armoured, Volatile, Cursed, Gilded, Frostbitten,
  Overcharged, Rootbound, Echoing, Hungry, Hoarder, Shiny
- elite/miniboss dressing layers
- clean silhouettes

Target:
~120 base pose assets + ~20–30 reusable overlay/effect assets.

This gives much more apparent enemy variety without needing hundreds of unique
creatures.

## S. Accessibility / Localization-Safe Art States

Art must support:
- color + icon redundancy for rarity
- strong contrast states
- disabled/selected/focused states
- text expansion without baked text
- no critical meaning encoded only by red/green
- scalable UI frames

No text should be baked into runtime UI images unless it is a logo.

## U. Final Art QA

No asset is “final” until:
- it matches the Style Bible
- it reads at actual runtime size
- no obvious AI/deformation/artifact issue exists
- transparent edges are clean
- weapon direction/pivot is correct
- silhouette remains readable
- it uses no protected third-party logos/characters
- it is named and filed correctly
- provenance is recorded if externally sourced
- it passes a real 480x854 render check once integrated

## Estimated Final Scope

The complete project should expect approximately:

- 80–90 playable-character/cosmetic pieces
- 75–85 weapon/projectile pieces
- 75–85 equipment pieces
- 140–160 enemy/variant pieces
- boss packages
- 60 major environment pieces
- 40–60 prop pieces
- 30–36 chest pieces
- ~40 NPC pieces
- 60–80 UI components
- 100–140 icons
- 40–60 VFX pieces
- 30–50 trophy/collection pieces
- 20–30 marketing/store pieces

This is roughly a 600+ deliverable art program, but modular reuse means the
number of unique high-cost illustrations can stay far lower.

That is the financially responsible way to make Lootlings look like a complete
game rather than an asset dump.
